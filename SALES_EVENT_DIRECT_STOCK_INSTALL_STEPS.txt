FINAL BUSINESS FLOW
-------------------
SALES + COMPONENT
- Select Component.
- Dropdown contains only free In-Store stock.
- MR-reserved stock is excluded.
- Save deducts quantity immediately.
- Exact serials are deducted automatically using FIFO.
- Sold stock is not restored.

SALES + DRONE
- Select Drone.
- Type drone name.
- Save creates the Sales record only.
- No MR link and no component Inventory change.

EVENT + COMPONENT
- Select Component.
- Save deducts quantity and exact serials temporarily.
- In Event Return, checked rows mean Returned Good.
- Returned Good quantity/serials are restored to In Store.
- Unchecked rows require remarks and are not restored.

EVENT + DRONE
- Select Drone.
- Type drone name.
- Save creates the Event record only.
- Return updates only the Event record.

NO APPROVAL FLOW
----------------
- No manager approval.
- New records use approval_status = NOT_REQUESTED.
- Stock movement happens immediately when Sales/Event is saved.
